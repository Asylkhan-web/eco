Электростатика негіздері

Электростатика — тыныштықтағы электр зарядтарының физикасы. Табиғатта найзағай, жабайы жануарлардың электр органдары (акула, электр жылан балығы) — бәрі осы заңдылықтарға бағынады.

Негізгі формулалар — Электростатика

F = k·q₁·q₂/r²Кулон заңы (k = 9×10⁹ Н·м²/Кл²)
E = F/q = k·Q/r²Электр өрісінің кернеулігі
φ = k·Q/rЭлектр потенциалы
I = U/RОм заңы
P = UI = I²RЭлектр қуаты

Тізбектей қосылу

R = R₁ + R₂
I₁ = I₂ = I— ток тең
U = U₁ + U₂— кернеу қосылады

Параллель қосылу

1/R = 1/R₁ + 1/R₂
U₁ = U₂ = U— кернеу тең
I = I₁ + I₂— ток қосылады

Магнетизм теориясы

Магниттік өрістер жер бетіндегі тіршіліктің ажырамас бөлігі. Аралар мен көші-қон құстары магнит өрісін навигация үшін пайдаланады — бұл табиғаттағы кванттық эффекттің нақты мысалы.

Магнетизм формулалары

F = qvB·sinαЛоренц күші
B = μ₀·I/(2πr)Ток жіпшесінің өрісі
Φ = B·S·cosαМагниттік ағын

Магниттік индукция B Тесла (Тл) бірлігімен өлшенеді. Жер магнит өрісінің кернеулігі ~25–65 мкТл шамасында — бұл Жерді космостық сәулелерден қорғайды.
