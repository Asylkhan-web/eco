Геометриялық оптика

Шағылу заңы

Жарық сәулесінің шағылу бұрышы түсу бұрышына тең:

α = α'

Сыну заңы (Снеллиус)

n₁sinα = n₂sinβ

n — сыну көрсеткіші, α — түсу бұрышы, β — сыну бұрышы

Толық ішкі шағылу

Жарық тығыз ортадан сирек ортаға өткенде критикалық бұрыштан артық болса, толығымен шағылады.

sinα_кр = n₂/n₁

Жұқа линза формуласы

1/f = 1/d + 1/d'

f — фокусты қашықтық, d — затқа, d' — кескінге дейінгі қашықтық

Кванттық физика

Жарық кванттары (фотондар)

E = hν = hc/λ

h = 6.626×10⁻³⁴ Дж·с — Планк тұрақтысы, ν — жиілік, λ — толқын ұзындығы

Фотоэлектрлік эффект

hν = A + mv²/2

A — шығу жұмысы, mv²/2 — электронның кинетикалық энергиясы (Эйнштейн теңдеуі)

Бор постулаттары

  • Электрон стационар орбитада сәуле шығармайды
  • Орбиталар квантталған: mvr = nℏ
  • Сәуле ұшырғанда: hν = E₂ - E₁

Атом ядросы

Ядро протондар (Z) мен нейтрондардан (N) тұрады. Масса саны A = Z + N. Байланыс энергиясы: ΔE = Δmc²

Бейнематериал: Өсімдіктер қалай қоректенеді? (Кванттық биология)

Жарықтың шағылу және сыну симуляциясы

5° 45° 85°
n₁ = 1.0 (ауа)

Есептеулер

Шағылу (α'): 45°
Сыну (β): 28.1°
Сыну к-ші: 1.50
⚠️ Толық ішкі шағылу!
Түскен сәуле — ауадан бетке бағытталады
Шағылған сәуле — бірдей бұрышта кері бағытта
Сынған сәуле — ортаға енгенде бұрышы өзгереді

Снеллиус заңы:

n₁·sin(α) = n₂·sin(β)

Жарық тығызырақ ортаға өткенде нормальға қарай иіледі (β < α). Сирек ортаға өткенде нормальдан алыстайды.
